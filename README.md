# ฟิล์มบล็อคสกรีน

เครื่องมือเตรียมฟิล์ม positive สำหรับถ่ายบล็อคสกรีน จากไฟล์ลูกค้า (.ai ที่บันทึกแบบ PDF-compatible, .pdf หรือ .zip)

- หากรอบแป้น แยกลายซ้าย-ขวา และแยกหลายลาย/หลายหน้าในไฟล์เดียว
- ตัดเส้นกรอบ เส้นร่าง เส้นบอกขนาด และคำอธิบายนอกกรอบออก ลายทุกสีเป็นสีดำ
- ระบุลูกค้า ความหนาบล็อก และชดเชยขอบ (อัตโนมัติ = ความหนา × 0.5 / ระบุค่า / ไม่ชดเชย) แยกแต่ละลาย
- กากบาท 3 จุดและข้อความใต้ลายเป็นสีเทาจาง เรียงทุกงานลงฟิล์มขนาด 21×31 นิ้ว (ปรับได้)
- ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มีการอัปโหลดไฟล์ลูกค้าไปที่ใด

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแอปและส่วนติดต่อผู้ใช้ |
| `js/film-core.js` | วิเคราะห์ไฟล์ หากรอบแป้น แยกลาย ชดเชยขอบ และสร้าง PDF |
| `vendor/` | pdf-lib 1.17.1, JSZip 3.10.1, PDF.js 3.11.174 (เก็บในเว็บเอง ไม่พึ่ง CDN) |

## Deploy บน Cloudflare Pages

Workers & Pages → Create → Pages → Connect to Git → เลือก repo นี้

- Framework preset: **None**
- Build command: *(เว้นว่าง)*
- Build output directory: **/**

ทุกครั้งที่ push เข้า branch `main` Cloudflare จะ deploy ให้อัตโนมัติ

## ทดสอบในเครื่อง

```
python3 -m http.server 8080
```
