# ฟิล์มบล็อคสกรีน (Viczo)

เครื่องมือเตรียมฟิล์ม positive สำหรับถ่ายบล็อคสกรีน จากไฟล์ลูกค้า (.ai ที่บันทึกแบบ PDF-compatible, .pdf หรือ .zip)
รันบน Cloudflare Workers (ฟรี) ใช้ฐานข้อมูล D1 ตัวเดียวกับแอปบันทึกขึ้นบล็อค (`stencil-db`)

- หากรอบแป้น แยกลายซ้าย-ขวา และแยกหลายลาย/หลายหน้าในไฟล์เดียว
- ตัดเส้นกรอบ เส้นร่าง เส้นบอกขนาด และคำอธิบายนอกกรอบออก ลายทุกสีเป็นสีดำ
- ระบุลูกค้า ความหนาบล็อก และชดเชยขอบ (อัตโนมัติ = ความหนา × 0.5 / ระบุค่า / ไม่ชดเชย) แยกแต่ละลาย
- กากบาท 3 จุดและข้อความใต้ลายเป็นสีเทาจาง เรียงทุกงานลงฟิล์มขนาด 21×31 นิ้ว (ปรับได้)
- ไฟล์ลูกค้าประมวลผลในเบราว์เซอร์ทั้งหมด ไม่ถูกอัปโหลดไปที่ใด

## การตั้งค่าที่ใช้ร่วมกัน
- **รายชื่อลูกค้าและความหนาบล็อกปกติ** อ่านจากแอปบันทึกขึ้นบล็อค (`settings.key = 'master'`, `customerSpecs[ลูกค้า].target`) แก้ที่แอปนั้น
- **การตั้งค่าอื่นของแอปฟิล์ม** (ขนาดฟิล์ม มาร์ค ข้อความ ความหนาที่มีให้เลือก ตัวคูณชดเชย) เก็บใน `settings.key = 'film'` ใครก็แก้ได้จากแท็บตั้งค่า บันทึกแล้วทุกเครื่องเห็นค่าเดียวกัน
- ถ้าต่อเซิร์ฟเวอร์ไม่ได้ (เช่นเปิดไฟล์ .html ในเครื่อง) แอปยังใช้ได้ แต่การตั้งค่าเก็บในเบราว์เซอร์นั้นเท่านั้น

## การ deploy
**อัตโนมัติ**: push เข้า branch `main` แล้ว Cloudflare Workers Builds จะ deploy ให้เองภายใน 1–2 นาที

ตั้งค่าครั้งแรก (ทำครั้งเดียว): Dashboard → Workers & Pages → Create → **Import a repository** → เลือก `film-positive`
- Build command: เว้นว่าง
- Deploy command: `npx wrangler deploy`

ฐานข้อมูล `stencil-db` ถูกผูกไว้ใน `wrangler.jsonc` แล้ว ไม่ต้องตั้งค่าเพิ่ม

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html` | หน้าแอปและส่วนติดต่อผู้ใช้ |
| `public/js/film-core.js` | วิเคราะห์ไฟล์ หากรอบแป้น แยกลาย ชดเชยขอบ และสร้าง PDF |
| `public/vendor/` | pdf-lib 1.17.1, JSZip 3.10.1, PDF.js 3.11.174 |
| `src/index.js` | API `/api/settings` (GET/PUT) |
| `wrangler.jsonc` | การตั้งค่า Cloudflare |
